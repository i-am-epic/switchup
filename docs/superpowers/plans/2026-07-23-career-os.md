# Career OS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a usable Next.js + Postgres Career OS with password auth, daily/overdue task reminders, roadmap modules, heatmap/streak, and a cozy Notion-cute UI.

**Architecture:** Single Next.js 15 App Router app. Prisma talks to Postgres (Docker Compose locally). Pure reminder helpers in `lib/reminders.ts`. jose JWT cookie for single-user password gate. UI uses Fraunces + Nunito with warm paper / matcha / candy pastel tokens.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS v4 (or v3 if scaffold defaults), Framer Motion, Prisma, PostgreSQL, zod, jose, vitest, date-fns-tz

## Global Constraints

- No AI features in v1
- No Kanban, no analytics charts beyond streak + heatmap
- Single-user password via `APP_PASSWORD`; session via jose HS256
- Timezone default `Asia/Kolkata` via `APP_TIMEZONE`
- Fonts: Fraunces (display) + Nunito (body)
- Module enum: `leetcode | backend | ai | azure | projects | articles | notes | interview | general` (Today is a view, not a module)
- Reminder classification order: Overdue → Today → Pending → Later → Unscheduled
- Do not commit unless the user explicitly asks
